# Retro Mix Arcade 1.2.1

This update brings the other five games closer to Sprint 2's CRT presentation.

- Vectoroid, Pong, Light Cycles, Tank Duel, and Breakout now share Sprint's
  rounded glass aperture, dark tube rim, and subtle lit edge.
- Scanlines are stronger and more consistent across the games. Sprint's shared
  scanline, glow, curvature, and intensity controls still govern the display.
- The glass frame is kept in a static layer so it does not need to be rebuilt
  for every animation frame.

The six AI games, Mixed mode, game-specific effects, and existing JMR unlock
codes are included.

## Installation

1. Expand the macOS ZIP and move `Retro Mix Arcade.app` to Applications,
   replacing the previous copy.
2. Open the app and click **Save selection**.
3. In **System Settings → Wallpaper → Screen Saver**, choose
   **RetroMixModern**.

Requires macOS 14 or newer. The app contains Apple Silicon and Intel code.
The [$5 JMR unlock item](https://buymeacoffee.com/mikaelmoran/e/585964)
remains available.

This archive is locally signed for development. For a smooth installation on
other Macs, a Developer ID signed and notarized archive is required.
